# Security and Responsible Research

## Project Scope

STELTH is a Windows-focused malware development project involving system interactions and monitoring-related functionality.

## Responsible Research

- Conduct research only on systems for which you have explicit authorization.
- Use isolated environments and synthetic test data.
- Do not access systems or collect private information without permission.
- Never publish credentials, personal data, or sensitive logs.
- Review repository files and commit history before making the project public.

## Reporting Security Issues

If you identify a security issue related to this repository, document the affected component, potential impact, and relevant evidence.

Avoid publishing credentials, sensitive data, or details that could expose other systems.

## Public Repository Guidance

Before publishing changes, review source files, screenshots, logs, and attachments for sensitive information.

Documentation should accurately describe project capabilities, limitations, and verification status.

## Disclaimer

This document describes the project's intended research boundaries. It does not constitute an independent security audit or certification.
